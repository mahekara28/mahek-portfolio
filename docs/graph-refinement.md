# A small map of the work

27 October 2026. This pass builds on the shorter personal portfolio rather than
adding a product pitch or another collection of decorative widgets.

## What changed

The former six-project list and separate preview gave the homepage the weight of
an index. The new first screen introduces Mahek and a single connected map. Only
three projects are featured below it. The existing Projects route keeps the full
nine-project collection and all implementation notes, limitations and evidence.

The map is bipartite: project nodes connect to real tools or concerns. Python is
shared by RouterFlow and Narrative Gap MCP; the GitHub API is shared by MCP Impact
and Narrative Gap MCP. Ollama, contract scanning and developer feedback show what
is different about each project. It is a curated relationship map, not live data
or a dependency graph between repositories.

Selecting a node highlights its connections and reveals a direct source link.
The matching project entry receives the same selected state. Titles remain normal
links, so the graph is optional for navigation. Native buttons support touch,
Tab, arrow keys, Home and End. Live text describes the selection to screen readers.
Only selected strokes animate, once; reduced-motion users see the settled state.
No dragging, pointer-following, auto-cycling or network requests are required.

## Why these projects

- **RouterFlow:** a small, inspectable Python/FastAPI application with local model
  calls and explicit keyword routing. Its limits stay visible in project details.
- **MCP Impact:** contract parsing, GitHub comparisons and bounded source-reference
  scanning offer concrete developer-tooling evidence.
- **Narrative Gap MCP:** Python ingestion of issues and pull requests connects
  engineering to developer experience. Its calculated proxies and incomplete MCP
  integration remain disclosed; it is not presented as measured community impact.

The official GitHub API inventory and all nine current repository heads were
checked again. Every head still matched the pinned review. The selected projects'
primary evidence files were fetched directly and reviewed. No project identities,
capability claims, statuses, revisions or evidence were invented or upgraded.

## Colour and composition

Light: limestone `#eee9e0`, raised paper `#f7f4ed`, charcoal `#282d30`, petrol
`#176268`, brass `#825d25`. Dark: ink `#172126`, surface `#202d32`, warm text
`#eee8da`, pale petrol `#8bc8c2`, brass `#dfbd7f`. Borders and secondary text have
their own tokens. Selection uses petrol; brass marks punctuation and the third
branch of the retained flow sketches. There are no gradients or glowing fields.

The original local fonts and line mark remain. The homepage has an asymmetrical
introduction/map pairing and three open project entries. Mobile stacks these with
the introduction first. A fine index line and expansion nodes carry the graph
language into the Projects page without repeating the map everywhere. Existing
flow sketches are available inside the corresponding expanded project notes.
